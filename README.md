# Site web Green World Cameroun — prototype

> Prototype HTML/CSS/JS généré avec Claude Design, basé sur le prompt
> [prompt-site-web-green-world.md](../prompt-site-web-green-world.md).
> Récupéré et intégré ici le 2026-06-08.

## Comment l'ouvrir

Double-clique sur `Green World Cameroun.html` : il s'ouvre dans le navigateur
et fonctionne hors ligne (tout est inclus : images, styles, scripts).

## Contenu

- `Green World Cameroun.html` — la page complète
- `assets/` — styles (`styles.css`), interactions (`script.js`), images produits et visuels
- `uploads/` — images supplémentaires importées pendant la conception

## Ce qui est déjà fonctionnel

- Bandeau promo qui alterne deux messages
- Menu mobile (drawer) et menu desktop
- Diagnostic / quiz qui recommande des produits selon le besoin
- FAQ en accordéon
- Carrousel de témoignages
- Boutons "Commander sur WhatsApp" déjà connectés au numéro **+237 6 80 19 06 34**
- Bouton WhatsApp flottant
- Compteur de panier (stocké localement dans le navigateur)

## À vérifier / personnaliser avant la mise en ligne

- L'adresse e-mail dans le footer est `contact@greenworld.cm` — à remplacer si
  ce n'est pas ta vraie adresse de contact
- Les liens "CGV", "Politique de retour", "Mentions légales" pointent vers `#`
  (pages à créer plus tard)
- Les prix et descriptions produits sont ceux du prototype — à ajuster si tes
  tarifs réels diffèrent

## Prochaine étape : mise en ligne

Ce prototype est un site statique : il peut être déployé tel quel sur un
hébergeur (Netlify, Vercel, ou un hébergeur classique), ou servir de base à un
développeur pour l'intégrer à une plateforme e-commerce (Shopify, WooCommerce).
